# Example 07: Eight-arm star strands

Each star has three bonded neutral center beads in a linear core. The two
outer centers carry three 32-bead PDMS arms each and the middle center carries
two, giving coordination four at every center. All eight outer arm ends are
functional, and each complete star contains 259 beads.

The example contains 450 stars and 900 four-functional crosslinkers at `1:1`
functional-group stoichiometry, for 145,350 beads in total.

Run from the repository root:

```bash
bash examples/07_star_8arm/run.sh
```

The generated package is written under `examples/07_star_8arm/star_8arm/` and
ignored by Git.
