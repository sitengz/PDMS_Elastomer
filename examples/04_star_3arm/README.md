# Example 04: Three-arm star strands

Each star has one neutral center bead and three 32-bead PDMS arms. The three
outer arm ends are functional, giving reactive bead sites 33, 65, and 97 in
a 97-bead star molecule.

The example contains 1,200 stars and 900 four-functional crosslinkers at
`1:1` functional-group stoichiometry, for 145,200 beads in total.

Run from the repository root:

```bash
bash examples/04_star_3arm/run.sh
```

The generated package is written under `examples/04_star_3arm/star_3arm/` and
ignored by Git.
