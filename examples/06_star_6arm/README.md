# Example 06: Six-arm star strands

Each star has two bonded neutral center beads. Three 32-bead PDMS arms attach
to each center, so both centers have coordination four. The six outer arm ends
are functional, and each complete star contains 194 beads.

The example contains 600 stars and 900 four-functional crosslinkers at `1:1`
functional-group stoichiometry, for 145,200 beads in total.

Run from the repository root:

```bash
bash examples/06_star_6arm/run.sh
```

The generated package is written under `examples/06_star_6arm/star_6arm/` and
ignored by Git.
