# Example 05: Four-arm star strands

Each star has one neutral center bead and four 32-bead PDMS arms. The four
outer arm ends are functional, giving reactive bead sites 33, 65, 97, and 129
in a 129-bead star molecule.

The example contains 900 stars and 900 four-functional crosslinkers at `1:1`
functional-group stoichiometry, for 144,900 beads in total.

Run from the repository root:

```bash
bash examples/05_star_4arm/run.sh
```

The generated package is written under `examples/05_star_4arm/star_4arm/` and
ignored by Git.
