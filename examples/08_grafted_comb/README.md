# Example 08: Comb-like grafted strands

Each strand has a 64-bead backbone and five 8-bead side chains. A graft
spacing of 12 leaves 12 ungrafted backbone beads between grafts, giving grafts
at backbone beads 1, 14, 27, 40, and 53. The requested functional fraction is
40%, so two evenly distributed side-chain ends are functional. Backbone ends
are neutral.

The example contains 1,200 comb-like strands and 600 four-functional
crosslinkers at `1:1` functional-group stoichiometry, for 144,000 beads in
total.

Run from the repository root:

```bash
bash examples/08_grafted_comb/run.sh
```

The generated package is written under
`examples/08_grafted_comb/grafted_comb/` and ignored by Git.
